
# 🚀 MEMO Update Guide (Raspberry Pi 5)

We have made significant changes to the Visuals (LCD) and Logic. To ensure your Pi runs smoother than before, follow these steps.

## 1. Pull Latest Code
On your Raspberry Pi terminal, inside the `MEMO` folder:
```bash
git pull
```

## 2. ⚠️ CRITICAL: Preserving Assets
**DO NOT RUN GENERATION SCRIPTS ON THE PI.**
The code includes high-quality assets that are not generated by the scripts. Running the scripts will overwrite them with lower-quality versions.

### How to Copy Assets to Pi
Since you have the correct assets on your Windows PC in `interface/lcd/assets`, you need to copy them to the Pi.

#### Option A: Network Transfer (Recommended)
Use `scp` or a tool like FileZilla/WinSCP.
```bash
# From Windows PowerShell (replace <PI_IP> with your Pi's IP, e.g., 192.168.1.15)
scp -r "interface/lcd/assets" pi@<PI_IP>:/home/pi/MEMO/interface/lcd/
```

#### Option B: USB Stick
1. Copy the `assets` folder from your PC to a USB stick.
2. Plug the USB stick into the Pi.
3. Run this on the Pi (assuming USB is mounted at /media/pi/USB):
```bash
cp -r /media/pi/USB/assets/* /home/pi/MEMO/interface/lcd/assets/
```

#### Option C: The "SD Card Trick" (Since you have the card plugged in)
Since Windows can only see the `bootfs` partition (Drive D: in your case), you can use it as a bridge.

1.  **On Windows**:
    *   Copy your `assets` folder (from `interface/lcd/assets`) and paste it directly into the `bootfs (D:)` drive.
    *   You should see `D:\assets` alongside files like `kernel8.img` and `config.txt`.
    *   Safely Eject the card and put it back into the Pi.

2.  **On Raspberry Pi (after booting)**:
    *   The `bootfs` partition is mounted at `/boot/firmware` on the Pi 5.
    *   Run these commands (Make sure you are inside your project folder!):
    ```bash
    # 1. Check where you are (Ensure you are in the project folder, e.g., ~/mino_main/memo)
    pwd 
    
    # 2. Clear old assets (SAFELY using relative path)
    rm -rf interface/lcd/assets

    # 3. Copy from boot partition (For Pi 5)
    # Note: /boot/firmware/assets is where you put it on the SD card
    cp -r /boot/firmware/assets interface/lcd/

    # 4. Verify
    ls interface/lcd/assets
    # You should see folders like 'idle_center', 'focus_scan', etc.

    # 5. (Optional) Cleanup the boot partition
    sudo rm -r /boot/firmware/assets
    ```

## 3. Run MEMO
```bash
./run_memo.sh
```
*(Or ./run.sh)*
*(Or your usual startup command)*
